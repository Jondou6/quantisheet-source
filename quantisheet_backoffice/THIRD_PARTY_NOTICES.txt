QuantiSheet Back Office - third-party libraries

Office briefs. It contains no code from other accounting programs. It uses
these libraries, which are installed with it (the same ones QuantiSheet
itself ships). Each line: distribution : licence.

Optional, not installed with Back Office and only used when already on
the PC: Microsoft Outlook (through pywin32, if present) to show an email
for review; the Tesseract OCR program (Apache-2.0) to read scanned bills.
Without them Back Office writes an .eml file / asks for the fields by hand.

Optional self-service server (server\, P2-07/08), only if you choose to
run it as its own service; not part of the desktop program. It uses the
Python standard library; its container image (server\deploy\Dockerfile)
adds:
  * waitress, licence ZPL-2.1 (WSGI server, installed only inside that image)
  * Caddy, licence Apache-2.0 (optional reverse proxy for HTTPS)
The server's web pages are plain HTML/JavaScript written for Back Office
and load nothing from other sites.
