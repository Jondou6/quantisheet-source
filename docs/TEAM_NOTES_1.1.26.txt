QuantiSheet 1.1.26
- Project Analysis reads more spec books: bid dates written with ordinals (December 17th), 'fully complete the work within N days', liquidated damages written several ways (the overtime clause is not taken for them), retention as well as retainage, 'the work to be done consists of' for the summary, insurance limits from a table, and the Owner's office address is not taken for the project address. The last day for questions is worked out when the specs count it back from the bid opening ('at least 7 days prior').
- Summarize with Local AI (inside the Project Analysis window): a short scope summary written by the AI on this PC from the first pages of the specs - nothing leaves the PC. It is marked as AI-written and kept with the answers.
- Send to Bid Board (in the Project Analysis window): a new Bid Board entry with the project name, address, city and state, bid due date and time, job walk, whether the pre-bid is mandatory, the last day for questions and the specs' scope summary - check it, then Save. Fill From Specs (in the Bid Board's edit window) does the same for an entry you already have, from the specs that are open. Only empty fields are filled; nothing you typed is replaced.
- Source code (GNU AGPL-3.0): https://github.com/Jondou6/quantisheet-source/tree/v1.1.26 - the full source of this build. Help > About shows the same link.
