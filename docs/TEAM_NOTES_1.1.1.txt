QuantiSheet 1.1.1
- Fixed: clicking QuantiSheet sometimes opened it twice. It now opens one window (File > New Window when you want a second).
- Fewer clicks: pick your role (Estimator, PM, Service, Office) and the tabs and quick bar fit it. Fewer tabs; a one-time card after this update lets you pick a role or put the old tabs back (also View > Ribbon Tabs). Buy Quantities, Typical Sheet, Carry Forward and Tags Check are on the Takeoff tab, Bid Form Workbook and Builder's Risk on the Estimate tab; one Compare button opens overlay, changes and text.
- Quick bar: right-click any button > Pin to Quick Bar; drag pins to reorder. One Export button remembers your last export.
- Right-click the drawing: Set Scale, Length, Area, Count, Edit Text Here, Redact Area, Snapshot, New RFI Here, Paste Here, Rotate This Page, Insert Pages Here.
- Ctrl+K finds sheets, takeoff items, RFIs and service records too; Shift+Enter shows where a button lives. F10 or Alt opens the menus from the keyboard. Help > Customize Shortcuts.
- Takeoff: number keys 1-9 pick Tool Chest tools and Space repeats the last tool. Copy and paste takeoff between sheets (re-measured at the new sheet's scale). Buy Quantities turns totals into sheets, boxes or rolls with waste. Tags vs Schedule Check, Carry Takeoff Forward, Typical Sheet, Color Takeoff By, Show Only This Item, Bulk Edit, Join and Split runs, arcs (Tab). Overlapping cutouts are counted once.
- A scale read from the title block stays marked "unconfirmed" (also after saving and on other PCs) and asks to be checked before your first measurement on that sheet. Opening a set no longer asks to save just because scales were read.
- New Service tab: calls, agreements, logs and tests (including a backflow test report), pricing, records and quotes.
- Back Office (Project > Office): Waiting on Me, crew board with Copy Yesterday's Crews, checklist templates, safety meetings, pre-task plans (sign and PDF), incidents (people, photos, recordable log), equipment (units and hours), warranty calls (assignee, photos, report), job cost report import with a preview and a duplicate check, duplicate invoices held for a reason, a separate approver, and Payroll Key & Approvals (it asks for a key backup until you make one).
- Safer files: a warning before a save breaks a signature; redacted text is really removed; takeoff data that drops off an emailed PDF can be put back; a file from a newer version won't be overwritten; "someone else has this open" on shared folders.
- Tools > Back Up My QuantiSheet Data and Restore (plus a weekly automatic backup). Sage export shows a preview and saves an undo file. Macros are checked before they run.
- Help > Check for Updates Now; Help > About shows "Up to date" and when it last checked. Updates are checked before they install, and the installer of the version you're on is kept so you can reinstall it.
- Also new since 1.0.6: Bid Form Workbook and Check an Addendum, Spec Book Risk Scanner, Builder's Risk Quote Request, Count From a Picture, and Package Tracker status.
- Source code (GNU AGPL-3.0): https://github.com/Jondou6/quantisheet-source/tree/v1.1.1 - the full source of this build. Help > About shows the same link.
